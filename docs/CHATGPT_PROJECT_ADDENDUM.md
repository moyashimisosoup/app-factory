# 「アプリ思いつき作成」プロジェクト用の短い追記

App Factoryを利用するチャットで重複作成や意図しない公開を防ぐための追記案です。

## プロジェクト指示へ手動で追加する文章

> 「新アプリ案：」は構想のみとして扱い、GitHubへの書込みを行わない。開発への採用が明示された場合はSession Deckの全体台帳と既存リポジトリを再確認する。公開の moyashimisosoup/app-factory には、公開して差し支えない名前・短い一般的説明しか登録しない。非公開のアイデア、学校関係、個人情報、秘密情報、Private RepoのURL、会話URLは公開Issue・PR・Actionsログへ載せない。申請Issueの登録は「採用」時、Private Repo作成は**対象Issueを特定した追加の本人承認**の後に factory-approved を付ける時のみ行う。新Repo作成、初期ファイルのcommit、APP-ID登録、Pages公開を別段階で検証し、未確認を完了と表現しない。GitHubの権限・Action Secret不足時は安全に停止する。

## 使い方

- 追記だけでGitHubのSecretは自動登録されない。
- ChatGPTへのGitHub接続がない/対象Repoを閲覧できない時は権限追加をユーザーに依頼する。
- 既存の早期CHECKPOINT/HANDOFF_READY運用は継続。
- Public App Factoryが受付正本。旧Privateブートストラップ案は再利用しない。
